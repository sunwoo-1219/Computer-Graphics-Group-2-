## 🎮 SUPERHOT 소개

**SUPERHOT**은 폴란드 개발사 SUPERHOT Team이 제작한 1인칭 슈팅(FPS) 퍼즐 액션 게임입니다.
일반적인 FPS와 달리 **플레이어가 움직일 때만 시간이 흐르는** 독특한 규칙을 가지고 있으며, 이 규칙 덕분에 총알을 피하고 적의 행동을 예측하며 한 수 앞을 계산하는 전략적인 플레이가 핵심이 됩니다.

시각적으로는 흰색 배경, 붉은색 적, 검은색 오브젝트로 구성된 미니멀한 스타일을 사용해 어떤 오브젝트가 위협이 되는지 한눈에 알아볼 수 있습니다.

<br>

## ⚙️ 핵심 게임 기믹

### 1. ⏱️ 시간 제어 (Time Control)
- 플레이어의 움직임(이동, 시점 회전, 행동)에 비례해 게임 내 시간의 흐름이 결정됩니다.
- 가만히 서 있으면 시간이 거의 멈추고, 빠르게 움직이면 시간이 정상 속도로 흐릅니다.
- 시간이 느려진 상태에서 날아오는 총알의 궤적을 확인하고 회피할 수 있습니다.
- 플레이어와 적 모두 **한 대만 맞아도 사망**하므로 시간 제어가 곧 생존 전략이 됩니다.

### 2. 🧱 오브젝트 상호작용 (Object Interaction)
- 바닥이나 적이 떨어뜨린 무기를 집어 들어 사용할 수 있습니다.
- 무기뿐 아니라 주변의 오브젝트를 **집어서 던져** 적을 공격하거나 무력화할 수 있습니다.
- 던진 오브젝트 역시 시간 흐름의 영향을 받아, 날아가는 동안의 궤적을 보고 다음 행동을 판단할 수 있습니다.

<br>

## 🎯 모작 목표

이 프로젝트는 SUPERHOT의 핵심 재미를 이루는 두 가지 시스템을 직접 구현하는 것을 목표로 합니다.

### 핵심 목표
- [ ] **시간 제어 시스템 구현**
  - 플레이어 입력(이동 속도, 시점 회전)에 따라 게임 시간 배율(time scale)을 실시간으로 조절
  - 적, 총알, 오브젝트 등 모든 동적 요소에 동일한 시간 배율 적용
- [ ] **오브젝트 상호작용 구현**
  - 오브젝트 줍기 / 들기 / 던지기
  - 무기 획득 및 발사, 총알 충돌 판정
  - 적이나 오브젝트에 맞았을 때의 피격 처리

### 부가 목표
- [ ] 한 대 맞으면 사망하는 규칙 적용 (플레이어 / 적 공통)
- [ ] 기본적인 적 AI 구현 (플레이어 추적 및 공격)
- [ ] SUPERHOT 특유의 미니멀한 그래픽 스타일 재현 (흰색 환경, 붉은색 적, 검은색 오브젝트)
